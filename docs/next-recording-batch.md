# 下一批錄音與文字：獨立回測

目標：用新場次評估既有上下文詞彙候選，分清「此錄音的腳本校對」和「能用於其他錄音的規則」。第一份錄音已被用於開發與修訂，不能再當未見測試集。

已固定本輪計畫：[church-vocabulary-pilot-20261019.json](../evaluation/plans/church-vocabulary-pilot-20261019.json)。保存模型版本、規則／程式 hash、指標與初步驗收。新資料結果若促使規則修改，需另記下一版候選，不能覆寫本輪固定比較。這是先行計畫，尚未收到新資料或完成真人評分執行器。

## 現在提供什麼

先提供兩份各約 5～10 分鐘、已獲准用於評估的錄音，以及各自對應文字。優先來自不同場次，若可取得也換不同講員。可沿用現有 MP3，不必先轉成特定取樣率；工具會先探測原音，不覆寫來源。

命名例如 `session-a.mp3` 配 `session-a.txt`，`session-b.mp3` 配 `session-b.txt`。TXT、SRT 或直接貼文均可。只需附非識別性的場次／講員代號、文字是否近似講稿或已聽音核對、已知朗讀差異（引用未讀、開頭結尾缺稿等）。權利及同意沿用實際已有的有效依據，私下登錄，不在 Git 公開。不要為了測試而編造姓名、語句或完美稿。

文字不必先百分之百對齊；可以帶括號引用或省略號，我們會保留原文，另核對錄音確實讀出的部分。但正式錯誤率只用經核對的逐字 reference，不能直接拿近似腳本算分。腳本輔助修訂和人工選擇少數替換，都不表示整份稿已確認。

若有第三份獨立錄音，先自行留存音檔和文字，最後測試再提供內容，避免開發時提前看到。若只有一場或同一講員，也能做範圍有限的分析，報告會限制結論，不宣稱對新講員有效。

## 建議內容

保留自然的聚會語音，不需要照詞表刻意朗讀。希望涵蓋書卷／人物／地名、禁食／羔羊／施浸／召會／童女等用語、章節數字，以及一般敘述。能有婚姻、演習、交通等一般語境與正常噪音更好，沒有就明列缺少的覆蓋；不額外捏造實際錄音片段。可把兩段不同內容視為同場的多個片段，但它們仍是同一群組，不能偽裝成不同場次。

## 收到後的工作

1. 探測音訊、保存 hash 與原稿，按真實場次／講員分組；同檔衍生片段不跨 split。
2. 使用固定 Whisper small／CPU int8 產生 raw ASR，既有腳本不加入 prompt。只在同一份 raw ASR 上套用凍結的候選規則，避免混入模型變更。
3. 對照音訊完成 reference 與詞彙位置標註，保留漏讀、口誤、數字及引用狀態；字形偏好不當作聲學辨識能力。
4. 評估整體及有覆蓋的場次／講員／詞彙／一般中文等分組。沿用固定 CER 正規化與位置對齊；未出現的詞、零分母或未完成標註列不足，不自動判通過。
5. 初步要求整體及已量測分組不退步、沒有新增的已確認誤改，且至少一處確認詞彙改善才可說候選有觀察到幫助。未命中規則是「尚無效益證據」，不是 100% 正確。

兩份短錄音只是試驗，不是充分的統計樣本；即使符合初步門檻，也不直接更新正式網站。這輪先做評估與資料準備，不啟動模型微調；訓練資料用途和更大的資料規模需另外確定。

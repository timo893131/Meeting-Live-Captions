# 教會詞彙人工審閱清單 v1

這是人工整理的常見用語，不是從恢復本或生命讀經擷取的詞典。所有項目均為待審閱，不是已核准規則。尚未加入正式 glossary.js，也不作模型訓練資料。

審閱時先確認聚會實際用法、可接受譯名，再提供正向及負向例句。不同概念與合法譯名不可僅因教會偏好就視為辨識錯字。

| 類別 | 目標詞／概念 | 待確認事項 | 不應直接替換的情境 |
| --- | --- | --- | --- |
| 書卷 | 創世記 | 經文情境中的「創世紀」是否可校正 | 港劇／作品名稱《創世紀》 |
| 書卷 | 腓立比書 | 「腓力比」是誤識還是引用其他譯名 | 原文引用、合法地名譯法 |
| 人物 | 耶穌、耶穌基督 | 耶蘇、基度等誤識需真實錄音佐證 | 討論字形、引述錯字 |
| 人物 | 保羅、亞伯拉罕 | 說話者實際姓名、同音人名 | 一般人物姓名 |
| 地名 | 耶路撒冷、加利利、哥林多 | 譯本及縮寫 | 地理或其他來源的合法譯名 |
| 屬靈用語 | 經綸 | 同音誤識及前後文 | 經論、經營等實際說法 |
| 屬靈用語 | 那靈 | 是否有斷詞或同音問題 | 那裡等一般語句 |
| 屬靈用語 | 靈、魂、心 | 分別標註聽見的概念 | 三者不可互相取代 |
| 屬靈用語 | 重生、救贖 | 確認實際誤識類型 | 不將近義神學詞自動互換 |
| 聚會 | 交通 | 保留教會語境 | 道路交通、交通工具 |
| 聚會 | 調和 | 保留教會語境 | 調和顏料、調和比例 |
| 聚會 | 配搭、擘餅、禱告 | 收集實際常見誤識 | 不因讀音相近就套用全域替換 |

## 如何回覆審閱

每一項記錄：詞彙、使用情境、接受的譯名、是否允許自動替換、正向例句、不可修改例句、審閱者與日期。沒有證據時填「待確認」。私人內容放在核准儲存位置，不在 GitHub issue 貼上。

建議先審閱「創世記、阿們、交通、調和、靈／魂」；它們能暴露現有全域替換與語意判斷的限制。審閱後仍需用獨立的真實錄音回測，不能只用這張清單判定規則安全。

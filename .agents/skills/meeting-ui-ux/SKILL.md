# 字幕 UI／UX

## 輸入與最小 context

先確認要改善的角色、具體情境及成功行為。讀 AGENTS.md 的共通規則，再定位 public/index.html、style.css、app.js 中相關片段；只有跨事件契約時加入 meeting-realtime。

## 流程

1. 描述現有問題：如長輩看不清、加入流程太長、字幕跳動、失去連線卻仍顯示收音。一般合理選擇直接做，不等待選擇配色。
2. 寫下代表性流程與狀態：個人收音、房主分享、觀眾加入；包含等待、收音、辨識錯誤、離線、結束。
3. 先改善字級、對比、行距、暫定／確定字幕區分、焦點與狀態，再增加裝飾；字幕更新不搶走鍵盤焦點。
4. 避免每次新字幕強制拉動正在閱讀歷史的觀眾；如更動捲動策略，包含回到最新字幕的清楚方式。
5. 手機觸控、長文字、放大至 200%、鍵盤與螢幕閱讀器通知皆納入風險檢查。不得僅憑一般 screenshot 宣稱符合完整 WCAG。
6. 使用現有瀏覽器工具或可重現的檢查；缺少瀏覽器時先完成可做部分，將真人／輔助工具檢查標示未執行。

## 交付與驗收

- 相關程式變更及代表性畫面／互動證據，錯誤訊息說明使用者可以採取的行動。
- 核對桌面及手機主要流程；UI 能渲染與真人辨識可用分開報告。
- 模擬 ASR 可驗證字幕流程；不宣稱已測實際麥克風、供應商服務或真實準確率。
- 不為純 CSS／文案變更新增鏡像實作測試。更動事件處理、加入或重連時跑對應功能檢查。
